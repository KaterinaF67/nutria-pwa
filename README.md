# Нутрия PWA — локальная версия

Это отдельная статическая версия «Нутрии» без Django, аккаунтов, Render и внешней БД.

## Что умеет
- шкалы нутриентов 0–200%: недобор, целевой диапазон и перебор выделены разными цветами, отметка 100% всегда видна;
- карточка нутриента: вклад записанных продуктов, полнота данных и варианты добора с предварительным расчётом КБЖУ;
- 7 793 продукта USDA FoodData Central SR Legacy и исходная русскоязычная справочная подборка;
- анкета: пол, возраст, рост, вес, активность, цель, аллергии, заболевания и личные заметки;
- процентные цели БЖУ и автокоррекция граммовок добавленных продуктов с предварительным просмотром и отменой;
- дневник по датам: завтрак / обед / ужин / перекусы;
- 114 стартовых продуктов;
- 61 нутриент, проценты нормы и полоски 0–200%;
- профиль и автоматическая рекомендация калорий/БЖУ;
- собственные продукты с полным составом;
- рецепты и пересчёт по массе готового блюда;
- история веса и простая недельная статистика;
- избранное;
- копирование предыдущего дня;
- экспорт/импорт полной резервной копии JSON;
- PWA: можно установить на телефон/ПК;
- offline cache после первого открытия.

## Где данные
Данные хранятся в localStorage браузера на конкретном устройстве. Они НЕ отправляются на GitHub Pages и не синхронизируются между устройствами.

Перед очисткой браузера, сменой телефона или браузера обязательно скачайте JSON через «Резервная копия».

## GitHub Pages
1. Создайте репозиторий, например `nutria-pwa`.
2. Поместите все файлы из этой папки в корень репозитория.
3. `git add . && git commit -m "Nutria PWA local v1" && git push`
4. GitHub → Settings → Pages.
5. Source: `Deploy from a branch`.
6. Branch: `main`, folder: `/ (root)` → Save.
7. Через несколько минут сайт будет на `https://USERNAME.github.io/nutria-pwa/`.

## Локальный тест
Service Worker не работает через `file://`. Для нормальной проверки:

```bash
python -m http.server 8000
```

и открыть http://localhost:8000

## Данные о продуктах
В приложении есть исходная русскоязычная подборка и 7 793 продукта из USDA FoodData Central SR Legacy (2018). У продуктов USDA доступна ссылка на первоисточник. Названия частично русифицированы для поиска, оригинальное наименование сохранено в карточке.

Пропуск значения в базе означает «нет данных», а не нулевое содержание. Это отображается в анализе отдельной пометкой. Анализ дневника не является диагнозом и не заменяет консультацию врача.
